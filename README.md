# Easter-for-20-years
This small app can show an Easter date and connected holidays for 20 year ahead. It would be convenient for orthodox calendars or something like that. App lang is russian. Это небольшое приложение может показывать дату Пасхи и связанные с ней праздники на 20 лет вперед. Оно было бы удобно для православных календарей или чего-то подобного.
