# Easter-for-20-years
This small app can show an Easter date and connected holidays for 20 year ahead. It would be convenient for orthodox calendars or something like that. App lang is russian. You can use it locally on your pc, just download a file and open it via browser  
Это небольшое приложение может показывать дату Пасхи и связанные с ней праздники на 20 лет вперед. Оно было бы удобно для православных календарей или чего-то подобного. Вы можете использовать его локально на своем компьютере, просто скачайте файл и откройте его через браузер.
